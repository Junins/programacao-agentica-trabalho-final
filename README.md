# Quem ainda entende este código?

Trabalho final de Programação Agêntica (IFSul, Passo Fundo). Individual.

| Onde | O quê |
|---|---|
| `proposta.md` | pergunta, hipótese, cenário (commit anterior ao código) |
| `produto/` | o sistema da semana acadêmica (Python 3, sem dependências) |
| `experimento/` | perguntas, conferência e manutenções |
| `registro/` | diário do agente, meu diário, verificações |
| `artigos/` | artigo |

Rodar: `cd produto && python servidor.py` · Testar: `cd produto && python -m unittest`

Os commits com autor "Claude Code (agente)" são do agente; os outros são meus.

## Ordem

1. Revisar e assinar `proposta.md`; conversar com o professor; definir o teto de gasto.
2. Rodada A (`experimento/perguntas-a.md`), depois `registro/decisoes-do-agente.md`.
3. `experimento/manutencao-1.md`, sem agente. Checkpoint.
4. `experimento/manutencao-2.md`, com agente. Checkpoint.
5. Rodada B (`experimento/perguntas-b.md`).
6. Preencher o artigo e a apresentação a partir do diário.
